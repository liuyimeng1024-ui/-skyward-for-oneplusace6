防回滚不是看 vbmeta。 这台机器的每个包 vbmeta 里都是 rollback_index = 4，看着像没有限制； 真正的 ARB 值在 xbl_config 分区的 OEM metadata 里。 设备 ARB 为 1 时，刷入 ARB 为 0 的包会硬砖——没有 fastboot，没有 9008，只能换主板。

可以刷的包

最新版 + 前 5 个，全部 ARB = 1

版本系统ARB依据

不要刷的包

ARB = 0，刷到本机（ARB 1）上必然变砖

版本ARB

怎么用

包要从官方 CDN 下载，链接是签名 URL，约十分钟过期，所以这里不存直链。 在 RomCloud 选版本、过一次人机验证即可拿到。

下载后校验 ARB 再刷： 

python scripts/ota-part.py "<OTA直链>" xbl_config x.img
arbextract x.img

机器可读的同一份数据：ace6.json
工具：koaaN/arbextract
